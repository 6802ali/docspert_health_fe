# React + Vite

Docspert Health – Frontend Technical Task

This is a React.js application created using Vite as part of a technical task for Docspert Health.

The application demonstrates a basic healthcare frontend system with authentication and core pages.


🚀 Features

1) Basic Authentication
2) Login Page
3) Registration Page
4) Home Page
5) Patients Page
6) Consultation Page

Dockerized setup using Docker Compose

To start the frontend application, run: docker-compose up
